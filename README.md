# StudyMate — Study Planner

A beginner-friendly, responsive study planner made with HTML, CSS and JavaScript.

## Features
- Add study tasks and choose a subject
- Mark tasks as completed
- Filter all, pending and completed tasks
- View task totals and daily progress
- Save tasks in the browser using localStorage
- Mobile-friendly layout

## Run on your computer
1. Download all four project files.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a **Public** repository on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` (README.md is optional).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then press **Save**.
6. Wait a few minutes. Your website link will appear in the Pages section.

## Note
This is a static website, so GitHub Pages can host it for free. Tasks are saved in the browser on the device being used.
